Leonida Platinum Log — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades, a guide with cited sources for each trophy, a roadmap to the platinum, missable flags, and a checklist that saves in your browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
